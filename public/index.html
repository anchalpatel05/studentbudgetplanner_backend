Server Side API

My Student Finance API

This server provides the finance app data that the My Student Finance React site loads on its Resources page.

Available Endpoints

GET

Get All Apps

Returns the list of budgeting, saving, and investing apps recommended for students.

/api/apps

GET

App Images

Each app's img_name points to an icon served from the images folder.

/images/mint.svg

Each app includes

  • _id number
  • name string
  • category string
  • price FREE or PAID
  • description string
  • color card theme
  • img_name image path
